# TV遥控器上下切台、OK播放与菜单焦点恢复

## Goal
优化 TV 遥控器交互：
- 仅在菜单隐藏时，DPAD_UP / DPAD_DOWN 直接切台并播放；
- 菜单显示时维持列表原生焦点导航；
- OK 键仅在频道项上触发播放；
- 菜单隐藏后再次显示时，焦点应优先恢复到“正在播放频道”的位置，而不是从头开始。

## Requirements
- 菜单隐藏时：
  - DPAD_UP 切换到上一个频道并播放。
  - DPAD_DOWN 切换到下一个频道并播放。
- 菜单显示时：
  - DPAD_UP / DPAD_DOWN 保持 RecyclerView 原有焦点移动逻辑，不做 Activity 级拦截。
- 保持 KEYCODE_CHANNEL_UP / KEYCODE_CHANNEL_DOWN 现有逻辑不变。
- OK 键行为：
  - 菜单内聚焦频道项时触发播放（维持现有点击语义）。
  - 菜单内聚焦分组头等非频道项时不触发播放。
- 菜单焦点恢复：
  - 隐藏菜单时保存当前滚动位置与焦点状态。
  - 再次显示菜单时优先按“正在播放频道”定位并恢复焦点。
  - 若播放频道当前不可见（如分组折叠），应先展开对应分组再恢复焦点。
  - 若播放频道无法恢复，再回退到隐藏前焦点位置。
  - 若隐藏前位置因列表刷新、分组展开/收起失效，再按“隐藏前焦点频道”定位恢复。
  - 仅在以上恢复均失败时，才回退到首项。
- 焦点恢复成功后，尽量将目标项滚动到更舒适的可视区域（接近列表中部），避免焦点长期停留在边缘。

## Acceptance Criteria
- [ ] 菜单隐藏时，按 UP 可播放上一个频道。
- [ ] 菜单隐藏时，按 DOWN 可播放下一个频道。
- [ ] 菜单显示时，按 UP / DOWN 不触发直接换台。
- [ ] 菜单中聚焦频道项按 OK 可以播放该频道。
- [ ] 菜单中聚焦分组头按 OK 仅执行原有分组逻辑，不触发播放。
- [ ] 菜单隐藏后再次显示，焦点优先恢复到正在播放频道位置，而非默认首项。
- [ ] 播放频道不可见时（如分组收起），可自动展开分组并恢复焦点。
- [ ] 播放频道无法恢复时，可按“隐藏前焦点位置/频道”继续恢复；全部失败时才回退首项。
- [ ] 焦点恢复后列表滚动位置更稳定，目标项尽量位于可视中部附近。

## Technical Notes
- 主要修改 `MainActivity.dispatchKeyEvent` 与菜单显隐/焦点恢复逻辑。
- 复用现有 `previousChannel/nextChannel` + `playChannel()` 链路。
- 在 `GroupedChannelAdapter` 增加“按频道定位行索引”与“按位置获取频道”的只读能力，用于焦点恢复。
- 不改变现有分组展开、频道点击与播放语义。
- 在 `RecyclerView.requestItemFocus` 成功后追加轻量滚动校正，使焦点项尽量靠近中部显示。
